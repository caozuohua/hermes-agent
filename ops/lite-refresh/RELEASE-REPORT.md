- 更新继续要求确认，启用更新前 full backup；无人值守更新遇到本地变更停止，不自动 stash。
- QPC 新技能已安装，必须 API 成功、获得 record_id 且回读一致后声明完成。实际生产表只做只读 schema 预检；写入与异常流程测试使用隔离 HTTP 目标，没有改表头或向真实知识库插入测试记录。
